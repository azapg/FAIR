## Abre FAIR

Usa el enlace de FAIR que te proporcione tu institución, profesor o administrador.

Entra con tu correo y contraseña, o elige **Continuar con Google** cuando esté
disponible. Si recibiste una invitación, abre su enlace para crear tu cuenta.
Consulta [Iniciar sesión con Google](/es/platform/integrations) para conectar una
cuenta existente.

## Encuentra tus cursos

Abre **Cursos** para ver tus clases, asignaciones y materiales. Si falta un curso,
pide a tu profesor o administrador que revise tu acceso.

- **Estudiantes:** abre una asignación para leer las instrucciones y entregar tu trabajo.
- **Profesores:** abre un curso para gestionar asignaciones, participantes y calificaciones.

Si estás instalando FAIR para ti o tu institución, consulta la
[guía de instalación](/es/development/installation) en **Desarrolladores y TI**.
